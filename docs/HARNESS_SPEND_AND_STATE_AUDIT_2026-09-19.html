Ranked fixes (filed as tickets)

  1. #1015 Per-ticket dedup for triage shards — ≈$1,000–1,500/day. Persist a per-key fingerprint (queue line minus timestamps and prose, referenced PR states, the key's RESULT set); identical → no shard. The tick brake stays as backstop.
  2. #1016 Cap and terminalize pre-plan re-plans — ≈$800–1,200/day. Two stale re-plans per ticket per 24 h, then a terminal defer-to-build marker (the build stage plans anyway). The in-flight ticket/bh-475-cap PR adds the three-outcome ledger for the no-plan case.
  3. #1017 review-prs dedup that survives a wiped ledger — prevents a $500–600/day recurrence. Ask GitHub (free) or the D1 verdict row for an existing harness review of this sha before buying; the file is a cache, not the truth.
  4. #1018 review-autopilot caches the review before posting — ≈$150–250/day. A failed gh pr comment re-posts from cache next tick with no model call; two empty outputs → terminal.
  5. #1019 Conductor never buys a fallback review it will reject — the loop plus ≈$250/day when OpenRouter-Fable serves. Claude-only intent to agent-call; one lane failure per (head, lane-health epoch); no re-arm from BLOCKED_HUMAN unless the sha moved.
  6. #1020 Cost-capture parity — makes ≈$1.2K/day visible. Price every openrouter / fireworks / codex row at write time; alert on blank-cost bursts; decide whether the anthropic/-via-openrouter rung should be opt-in per stage.
  7. #1021 Consume a failing single-session triage after 3 attempts.
  8. #1022 Age out post-merge QA requeues — a dead feed, not a spend.
The cross-cutting rule these share: the dedup store must be a durable, shared record (GitHub itself or the D1 jobs worker), read before the call, with the three outcomes written back. Part two of this report is the inventory of every fact that still lives only in a file on one box.

No database twin at all (a hub wipe repeats paid work)

  • state/merge-conductor/attempts.txt: 396 KB, 5,240 lines, 65 read/write sites. A hub rebuild rehydrates PR state from D1 but starts with an empty attempts file, so it re-approves, re-rebases and re-kicks CI on every open PR.
  • state/deploy-queue/: a train that departs and fails its ledger write leaves nothing anywhere.
  • The entire alerts substrate: one alert lives in up to six mirrors (ALERTS.log + cursor, per-alert JSON, per-box quarantine drained over ssh, families, deferred spool, medic parks, ≈250 day-stamped flags/alerted-*) plus the console DB. No alerts table exists.
  • Fly machine registry and pool claims; routing enrollment flags (builder-fly-*, fly-pool-*, pool-halt-*) propagated by rsync and edited by hand on two boxes.
  • Blocked-resolver ladder counters: a wipe resets MAX_REBUILDS=3 to three more full builds per parked PR.
  • Review-autopilot markers and daily spend caps; external-PR verdicts (never reach job_artifacts); postmerge-qa-done.txt, whose header promises a ledger that no code writes.
  • state/overlap-defer/: written, never read back, so a ticket re-offered to another box buys the plan again, the exact loop the file exists to stop.

What stays on the filesystem, on purpose

  • Build worktrees, builds/<record>/ artifacts, plans/ contents, the repos: the work itself. The DB holds pointers and verdicts, not the tree.
  • Logs as logs (logs/*.log, cost.csv as write-ahead, ALERTS.log as the local audit trail): append-only and hardened; what changes is that nothing reads them to decide.
  • locks/*.lock for in-process mutual exclusion on one box only. What must not remain is a lock file used as a fleet-wide claim or a liveness probe.
  • Identity and credentials (state/box-id, state/box-name, env/*, App tokens, account files): bootstrap material that must work with no DB.
  • Caches with a TTL whose loss is a cache miss, not a fact loss (the lease cache, gh-budget, overlap-guard PR lists, model prices once the table is the source).
  • The fifteen legitimately clocked lanes (watchdog-ping, state-backup, harden-state, clock-sync, disk-clean, meter polls, security-scan, digests, weekly reviews): they keep their cadence and should write rows, not files.
