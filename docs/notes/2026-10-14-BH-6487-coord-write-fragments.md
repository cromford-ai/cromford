# A new coord write route is a fragment file, not a row in WRITES (BH-6487)

Doc: CONSOLE, console-ui/README.md

## What changed
Every console write route was one row appended before the `];` of `WRITES`
in `console-ui/functions/api/coord/[[path]].js`. Two branches that each added
a route edited the same hunk, and the merge conflicted.

- `WRITES` is closed. Its 37 rows stay where they are. A new row is a new
  file, `console-ui/functions/_lib/coord-writes.d/<NNNN>-<slug>.js`, where
  `<NNNN>` is the ticket number. The file is `export default [ <rows> ];` and
  imports only from `console-ui/functions/_lib/coord-writes.js` (`isStr`,
  `isScalar`, `jsonError`).
- The steer row (BH-5839) moved to `coord-writes.d/5839-steer.js`, so the
  live path runs through a fragment.
- The proxy matches `ROUTES = checkWrites([...WRITES, ...FRAGMENT_WRITES])`.
  The fragments load in numeric-prefix order. Two rows with the same method
  and the same string path refuse to load. A file name that is not
  `NNNN-<slug>.js` refuses to load.
- `FRAGMENT_WRITES` comes from `#coord-writes` (`console-ui/package.json`
  `imports`). Node gets `console-ui/tests/lib/coord-writes.node.js`, which
  reads the directory. The Pages bundle (wrangler, `workerd` condition) gets
  `console-ui/functions/_lib/coord-writes.gen.js`. That file is generated by
  `console-ui/scripts/coord-writes-build.mjs` and git ignores it.

## Where the render runs
- `npm run build` in `console-ui/` runs the generator before `vite build`.
  That covers `bin/console-pages-deploy.sh`, the PR-head build in
  `bin/console-preview-deploy.sh`, and CI.
- `bin/console-postmerge-qa.sh` and the main-functions tree of
  `bin/console-preview-deploy.sh` copy only `functions/` and `src/`.
  `cpv_coord_writes` (`bin/lib/console-preview.sh`) adds `package.json` and
  `scripts/` from the same sha and renders. A sha that predates the split is
  not touched. A failed render is `NOT_COVERED deploy tree failed (coord
  write table: <why>)` in the post-merge run, and a box-side stop in the
  preview run.

## Add a write route
1. Create `console-ui/functions/_lib/coord-writes.d/<ticket>-<slug>.js`.
2. Run `cd console-ui && npm test`.

Suites: `tests/coord-writes-fragments.bh-6487-test.sh`,
`console-ui/tests/coord-writes.bh-6487.test.js`.

`functions/_lib/coord-writes.gen.js` exists. `npx --yes wrangler@3 pages
functions build --outdir <tmp>` (wrangler 3.114.17, the major version that
`bin/console-pages-deploy.sh` deploys with) printed `Compiled Worker
successfully`, rc 0.
- The bundle's module markers name `_lib/coord-writes.gen.js` and
  `_lib/coord-writes.d/5839-steer.js`. The bundle contains `path: "steer"`.
- `readdirSync` occurs 0 times. `tests/lib/coord-writes.node.js` is not in it.
- Negative control: the same build with the `workerd` key removed from
  `imports["#coord-writes"]` takes `../tests/lib/coord-writes.node.js`, and
  `readdirSync` occurs 2 times. So the `workerd` condition is what selects the
  generated file.
