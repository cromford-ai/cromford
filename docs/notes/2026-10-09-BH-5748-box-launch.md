# One command launches an Orgo box (BH-5748)

Doc: ADDING-A-BOX, SCALE-PLAN-2

## What changed

- `bin/box-launch.sh <id> --project <p> --account <a>` makes one Orgo box and
  takes it to a passing smoke in 13 steps: capacity, create, running, tailnet,
  hubkey, harness, envfiles, migrate, ghapp, register, merged, bootstrap,
  smoke. The default is a dry run. `--apply` needs
  `--confirm-monthly-usd <n>` equal to the computed price until the computer
  exists.
- `catalog/orgo-plans.json` records the Orgo plan limits, the add-on pool, the
  prices, the template and the default specs per account. The numbers left
  `docs/SCALE-PLAN-2.md`. Pool sizes, the disk price and `template_ref` are not
  recorded anywhere, so they ship `null`, and `--apply` refuses until an
  operator sets them.
- `env-templates/lanes/380-box-launch.env.example` documents the
  `BOX_LAUNCH_*` knobs.

## Why

A new box was a chain of hand steps across the Orgo console, the box shell,
the hub and a PR. Nothing checked that each one was done, and nothing checked
the pool or named the monthly cost before the computer was bought.

## Rules it keeps

- Never a second computer. The state file holds the Orgo id. Before a POST, the
  script also looks for a computer named `<host>` on the account and adopts it.
- Absent is not zero. An unknown `GET /computers` shape, an entry with no
  numeric cpu/ram or a `null` pool stops the run. It is never read as free
  capacity.
- No secret is printed. The tailscale key rides the Orgo request body only. Env
  files are compared by sha256 and reported as `match` or `differ`.
- The harness clone has a credential. A new box has no GitHub login until the
  envfiles and ghapp steps. The hub mints a short-lived token with
  `bin/gh-token.sh` and sends it as the first ssh stdin line. The box script
  uses it only for the clone, the pull and `harness-sync.sh`. A sync failure
  fails the step; it is not stamped.
- Bootstrap waits for the register change on `origin/main` (exit 4), because
  `bin/bootstrap-machine.sh` reads the box id from the `fleet.conf` row.
- The script never commits, pushes or opens a PR.

## Not proven

`POST /computers/<id>/bash` is still unproven from this repo (see the header of
`bin/lib/restore-drill-orgo.sh`). The tailnet and hubkey steps depend on it.
`tests/box-launch.bh-5748-test.sh` stubs Orgo, ssh and scp: it proves the step
logic, not the endpoint.
