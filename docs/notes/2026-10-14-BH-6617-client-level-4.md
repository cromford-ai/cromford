# A lead|human post sends client level 4, and an old lib is named (BH-6617)

Doc: MERGE-CONDUCTOR, MERGIFY

## What happened

On #6472 a human MERGE was posted on head `72584ef8b321`. The bot dismissed
review 5505927398 on an older head at 04:11:29Z. The bot BLOCK review
5507704685 on the SAME head stayed CHANGES_REQUESTED. Mergify queues only on
`#changes-requested-reviews-by=0`, so a person dismissed it by hand at 04:11:59Z.

main already dismisses that review: BH-6548 (#6577, merged 04:00:44Z) added
mode `verdict` to `bin/lib/lead-stale-review.sh`. The review carries the
`<!-- lead-review:` marker, `user.type` Bot and login `cromford[bot]`, so
the mode-verdict filter selects it. The BH-6548 suite run with the pre-BH-6548
lib gives `rc=0 puts=1 id1=CHANGES_REQUESTED id2=DISMISSED`: the prod result.
So the post came from a checkout older than BH-6548, and it failed silently.

## What changed

1. `LV_CLIENT_LEVEL` in `bin/lead-verdict.sh` is 4. Level 4 means a lead|human
   MERGE dismisses the bot BLOCK on the same head. BH-6548 left the level at 3,
   so no `lead_verdict_min_client` value could refuse an older checkout.
2. `bin/lib/lead-stale-review.sh` sets `LSR_MODES='merge block verdict'`.
3. `lv_dismiss_stale` checks `LSR_MODES` before a mode-verdict call. A lib
   without `verdict` gets the older-head pass and one stderr line:
   `lead-verdict: <dir>/lib/lead-stale-review.sh predates BH-6548, so a lead
   BLOCK review on the same head <sha12> of <repo>#<pr> was not checked; git
   pull this checkout and re-run this post`. The exit stays 0.

The worker does not change. It compares any integer level with the row.

## Operator step after deploy

This PR does not raise the row. At row 4 the worker refuses (426, "git pull")
every lead, human or risk-tier post from a checkout below level 4, the Mac
included (`LEAD_TOKEN_SOURCES`, `worker/jobs/src/routes/verdicts.js`). Pull
every checkout that posts those verdicts, then run:

```
bin/jobs-client.sh setting-set lead_verdict_min_client 4   # refuse pre-BH-6548 clients
```

Source box posts send no level, and the row does not apply to them.

Tests: `tests/lead-verdict-skew.bh-6617-test.sh`.
