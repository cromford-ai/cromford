# The duplicate-close guard (BH-6929)

Doc: PR-OWNERSHIP

## What happened

On 2026-10-15 at 17:11-17:12Z, `bin/pr-owner-sweep.sh` closed
example-org/project-6 #721 and #746 as duplicates of #770. All three are TK-702.
They are stacked slices of one ticket: head `46622cec` (#721) is an ancestor
of head `32eca310` (#746), and both are ancestors of head `7550cf02` (#770).
#721 and #746 had APPROVE reviews and were queued to merge. The orchestrator
reopened both.

`po_superseded` rule 3 made the close. Its only stack check (BH-6814,
`PO_STACKED`) finds a PR whose BASE is this PR's head branch. The three
project-6 PRs all have base `main`, so the check did not see the stack.

## What changed

- New `po_dup_guard` in `bin/lib/pr-owner/dup-guard.sh`. Rule 1 and rule 3 of
  `po_superseded` and the sweep's `close-duplicate` arm call it before the
  comment and the close. It keeps a PR that is a slice, is named in another
  PR's `Blocked-by:`, is armed or approved, was reopened, has a "not a
  duplicate" comment, or shares a stack with another open PR of its key.
  docs/PR-OWNERSHIP.md §12 has the table.
- The `stacked` check works in both directions. A newer PR stacked on an
  armed, older keeper is not closed either.
- A failed read keeps the PR (`guard-unread`).
- The open-PR list reads `latestReviews` too.
- When a run closes a PR as a duplicate, the repo's one alert of the run goes
  out as critical (`bin/lane-alert.sh --severity critical`, Telegram now) and
  names those PRs. It is still one alert per repo per run.
- `PR_OWNER_REPO_ROOT` (default `/root/repos`) names the checkouts the git
  ancestor check reads. A repo with no checkout uses the REST compare.

## Known limits

- A rebuild that branched from an older PR's branch keeps that older PR open:
  the heads are one stack. The age ladder (`bin/lib/pr-owner/stale.sh`) still
  handles it.
- The orchestrator posts as the harness identity, so an "orchestrator
  comment" has no mark to match. `armed` (conductor state) and `approved`
  cover it.

Test: `tests/pr-owner-dup-guard.bh-6929-test.sh`.
