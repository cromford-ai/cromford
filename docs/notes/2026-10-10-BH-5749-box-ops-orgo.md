# Restart, stop, resize and retire an Orgo box (BH-5749)

Doc: ADDING-A-BOX

## What changed

- `bin/box-ops.sh` takes a verb as its first argument: `restart`, `stop`,
  `resize` or `retire`. The verbs are in the new lib `bin/lib/box-ops-orgo.sh`.
  With no argument, `box-ops.sh` is the cron tick, as before. Any other first
  argument is now a usage error (exit 2). Before this change, the script
  ignored the argument and ran the tick.
- The default is a dry run. `--apply` does the work. The exit codes are the
  same as `bin/box-launch.sh` (0, 1, 2, 3 NEEDS PURCHASE, 4 WAITING), so the
  console handlers (Wave 4, #5750) read one contract.
- `stop` publishes a `paused-<p>` row for each project on the box before it
  stops the computer. If one row does not land, the computer is not stopped.
- `resize` prices the change from `catalog/orgo-plans.json`. It checks the
  pool when a dimension grows, and it needs `--confirm-monthly-usd` equal to
  the added `$/mo`. It drains with `bin/quiesce-for-resize.sh` over ssh before
  the PATCH. It checks the `results` array of the answer, then reads the specs
  again.
- `retire --to <box>` moves the projects and runs
  `box-register.sh --retire`. `retire --delete --apply` deletes the computer
  only after `origin/main` no longer names the box. The new state file
  `state/box-ops/<id>.json` keeps the host, the Orgo id and `deleted_at`.
- `box-register.sh --retire` exit 3 (the BH-1965 trap-eval order) is reported
  as exit 2, because exit 3 means NEEDS PURCHASE in this contract.

## Why

Parent #5744 needs these operations as commands, under the same rules as
`box-launch.sh`: a dry run first, an owner confirmation that names the monthly
cost, a NEEDS PURCHASE line when the pool is short, and no secret in the
output.

## Not proven

`POST /computers/<id>/stop`, `PATCH /computers/<id>/resize`,
`DELETE /computers/<id>` and the shape of the resize `results` array are not
proven against the real Orgo API. `tests/box-ops-orgo.bh-5749-test.sh` stubs
Orgo, ssh and `box-register.sh`. No real box was operated.
