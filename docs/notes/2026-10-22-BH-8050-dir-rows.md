# A directory row that is not a scan selects only the files it names (BH-8050, slice C0)

Doc: TESTING, MERGIFY

## What changed

`bin/test-impact.sh` gave a suite a whole-directory row (`bin/`, `bin/lib/`)
for any rooted token that ended at a directory, and gave a bin script an edge
to its whole lib directory for a `source` line with a dynamic tail. On main
5c6ea6c4, 296 suites carried a `bin/` row. A change to one lane script
selected about 300 suites through that row alone.

The new lib `bin/lib/test-impact-dir-rows.sh` narrows two shapes, and only
these two:

- A loop-bound tail: `for f in a.sh b.sh; do cp "$DIR/bin/$f" …`. The row
  becomes `bin/a.sh` and `bin/b.sh`.
- A whole copy into a scratch tree: `cp -a "$DIR/bin" "$T/bin"`, then
  `bash "$T/bin/x.sh"`. The row becomes `bin/x.sh`.

The same rule replaces a source edge such as
`for _l in p.sh q.sh; do . "$H/bin/lib/$_l"; done` with edges to the two
files. A scan, a tail it cannot bind, and a treedir, learned or regression row
keep the directory. The header of the lib has the full rule and its K cases
(tests/test-impact-dir-rows.bh-8050-test.sh).

Env `TI_DIR_ROWS=0` is the old map; any value other than empty, 0 or 1 is
also off and says so once. `bin/test-impact.sh inputs` (the suite fingerprint)
always builds the old map, so no suite-ledger fingerprint moves. A map build
that narrowed something prints one
`dir-rows: narrowed <k> directory row(s) of <s> suite(s), <e> edge(s)` line.
`audit` keeps an empty stderr.

The new verb `bin/test-impact-mix.sh` prints the selection of the last N
merges by reason. The tables below come from it.

elsewhere in the suite). The `bin/lib/` rows come mostly through three
sourced libs whose dynamic tail is a function argument
(bin/lib/pool-push-rejected.sh, bin/lib/file-children.sh) or a list continued
with `\` (bin/board-conformance.sh).

## Owed by later slices

The ticket target is under 200 suites for a lane diff and a median batch
under 300. C0 does not reach it:

- C1: cut `catalog/test-impact-always.txt` to whole-repo invariants (84
  always suites run on every diff above).
- C2: a comment-only change keeps only self, reads, learned, regression and
  always rows, and the same rule inside rule P of
  `bin/lib/test-impact-fn-reach.sh`. Then the size test bounds tighten.
