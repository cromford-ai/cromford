# web-task type_secret action, redactor and screenshot mask (BH-7891, slice C0)

Doc: DB-COORDINATION-SPEC

## What changed

This slice follows `docs/notes/2026-10-23-BH-8125-type-otp.md` (the
`type_otp()` action module). It adds the behavior of the `type_secret(field)`
tool action as a module. The web-task agent does not call it yet: S1 (#7594,
PR #7650) is not on main, so slice C1 of #7891 wires it into the agent loop.

- `bin/lib/web-secret-action.mjs`: `createTypeSecret({ project, site,
  valueFor })` returns `{ typeSecret, redact, maskSelectors }`. One instance
  per agent run. Project and site are fixed at creation. The model names only
  the field.
- `typeSecret(field, fill, selector)`:
  1. The field must match the vault worker's field rule
     (`^[a-z0-9_.-]{1,64}$`). Else `refused: bad field`. No vault read.
  2. A field that starts with `totp_` is refused:
     `refused: field not allowed (use type_otp)`. A TOTP seed reaches a page
     only as a code, through `type_otp`.
  3. `valueFor(field)` reads the value. The default runs `wv_read` of
     `bin/lib/web-vault.sh` through bash. No value is on any argv.
  4. The value joins the run's redact set, then `fill(value)` types it.
  5. On success, a non-empty `selector` joins the mask list.
- Outcomes (the text the model sees, never the value):
  - `ok: secret typed (<field>)`, not terminal.
  - `refused: bad field` and `refused: field not allowed (use type_otp)`,
    not terminal. No read, no fill.
  - `error: secret unavailable (<provider line>)`, terminal. No fill. A retry
    cannot fix a missing credential or a vault refusal.
  - `error: secret fill failed (<message>)`, not terminal. Each typed value
    in the message is replaced by `[secret]`.
- `redact(text)` replaces every value typed in this run, longest first, with
  `[secret]`. It has no minimum length.
- `maskSelectors()` holds `input[type="password"]` from the start, then each
  recorded selector once.
- `screenshotOptions(page, secrets, base)` returns `base` with a `mask` of
  Playwright locators for every mask selector. A `base.mask` array is kept.
- No knob, no table, no worker route.
