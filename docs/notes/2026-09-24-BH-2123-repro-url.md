# Pre-build repro gate: the PR-body URL line is a capped code span

Doc: repro-gate

## What changed

- `pr_pr_section` in `bin/lib/prebuild-repro/render.sh` prints the reproduced
  URL in an inline code span (one backtick longer than its longest backtick
  run, a space inside each delimiter) and caps it at 500 characters, with
  ` [truncated]` after the span when cut. A missing URL still reads
  `URL: not recorded`.
- `docs/repro-gate/render.md` says so in the gate-to-output table and the
  fence rule.

## Why

BH-2123: the URL was the one free-text field in the reproduced section that was
neither fenced nor capped. A REPRO_URL holding `fixes #12` or an `@mention`
rendered live in the client repo's PR body, where it could close an issue or
ping someone.

The steps and observed fences, the not-reproduced and skipped lines, and
`pr_brief_line` are unchanged.
