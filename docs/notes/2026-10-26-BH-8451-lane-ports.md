# Lane ports onto the tracker contract, slice C3 (BH-8451)

Doc: tracker-adapter

## What changed

Slice C3 of #7920. Nine lanes stop reading "which tracker" from fleet.conf
column 4 for a Jira or Linear project. Column 4 says `-` for those projects
too, so each lane read the code repo's GitHub issues as their tickets. Now
each lane asks `tracker_kind` through the new seam `bin/lib/trk-lane.sh`, and
for `jira` or `linear` it reads through `tracker_context` + `tracker_list`.

THE TRIGGER is C0's rule (`bin/triage-gate.sh`). A lane asks `tracker_kind`
only when `<env dir>/<project>.env` has a `JIRA_BASE=` or `LINEAR_API_KEY=`
line with a value. Every other project makes 0 new settings calls and runs
the same code as before. Any answer other than `jira` or `linear` (`github-issues`,
`board`, no answer) keeps the lane's own path.

`trk_lane_list` adds the adapter's build label (`TRK_LINEAR_LABEL` or
`TRK_JIRA_LABEL`, default `ai-build`) when the caller gives no `--label`. The
server query already asks for that label. The flag makes the contract's own
check drop an unlabelled row as well.

## The allowlist

`tests/fixtures/tracker-direct-allowlist.txt` keeps every line. Each ported
file keeps its GitHub or board arm, and that arm still makes a direct call:
`bin/unblocked-children.sh` (column 4), `bin/hotfix-seen.sh` and
`bin/lib/triage-hotfix-lib.sh` (the GitHub issue list),
`bin/lib/untriaged-board-read.sh` (the board `/boards` read),
`bin/scheduler.sh` (the GitHub issue reads), `bin/preplan-candidates.sh`
(column 4, the GitHub list, the board `/tickets` read), `bin/run-preplan.sh`
(the board `/tickets/<id>` read) and `bin/launch-fastpath.sh` (column 4 and
the GitHub reads). `bin/untriaged-wake.sh` was never listed.
`bin/lib/trk-lane.sh` makes no direct call.

## Calls per enrolled project

Per hour, at today's cron rates: hotfix-seen 6, triage_hot_load 6, preplan
up to 30, scheduler up to 24 (12 open lists + at most 12 lazy `--state all`
lists), untriaged-wake 6. About 72 Linear or Jira requests, under Linear's
1,500 per hour per key. No new alert and no new knob.
