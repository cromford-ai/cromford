# One `lane_env_apply` does bounded shell work (BH-7494 r2)

**What it is:** after #7499 cut the settings loader, one `lane_env_apply
fly-pool <project>` still spent its CPU in `bin/lib/lane-gate.sh` and
`bin/lib/lanes-registry.sh`. This change removes the per-knob loops and the
forks the profile named. The exports are unchanged.

| change | where | before | after |
|---|---|---|---|
| lower-case a name with `${1,,}` (bash 4+; the character loop stays for 3.2) | `_lg_lower` | about 100 traced commands per name | 1 command |
| one jq and one eval for the registry memo | `_lg_km_load`, `_LG_KM_JQ` | about 30 traced commands per knob | a count that does not grow with the knob count |
| the registry path is resolved once, in the lane's own shell | `_lg_registry`, `_LG_REG_OUT` | 3 resolves, 3 `cksum`, 3 `tr` | 1 resolve, 1 `cksum`, no `tr` |
| the stamp key by expansion, not a `tr` fork | `_lr_stamp` | `cksum` and `tr` | `cksum` |
| no fork for the clock on bash 5 | `_lg_now_set`, `_lg_now` | one `date` per read | `$EPOCHSECONDS` |
| no subshell per key, lookup, meta field or number test | `_lg_setting_key_set`, `_lg_setting_lookup_set`, `_lg_knob_meta_set`, `_lg_isnum` | about 12 forks per knob read | none |

**How to drive it:**

| what | how |
|---|---|
| the acceptance cases | `bash tests/lane-env-cost.bh-7494-r2-test.sh` and `/bin/bash tests/lane-env-cost.bh-7494-r2-test.sh` |
| commands per registry load | `bash -c '. bin/lib/lane-gate.sh; trap "_C=\$((_C+1))" DEBUG; set -T; _C=0; _lg_km_load "$LANE_REGISTRY" lanes <id>; echo $_C'` |
| time on the hub | copy the lib to a scratch dir, point `HARNESS` at a scratch copy of the catalog and the settings cache, time `lane_env_apply fly-pool <project>` |

**Kill knobs:** none.

**What must never regress:**

- One `_lg_km_load` of a 72-knob lane runs at most 60 shell commands and one jq (C1).
- One `lane_env_apply` resolves the registry once: one `cksum`, one `find` (C4).
- One `lane_env_apply` of the 72-knob fixture runs in at most 60 processes and 12,000 traced lines (C5).
- The exports of 5 lane/project pairs and one lib, and 39 `lane_knob` reads, are byte for byte the golden file written by the #7499 library (E3).
- A registry memo has the same env list and the same eight fields per knob as before (E1).
