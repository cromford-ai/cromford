# Contract changes on the console project page (BH-9929)

**What it is:** the step ledger of the contract-change lane. A non-additive
schema change runs as 3 ordered PRs per parent ticket: `expand`, `migrate`,
`contract`. Each step PR records one row. The console project page lists the
rows.

## How to reach it

1. Open the console.
2. Open FLEET (or the projects list) and click a project, for example
   `project-6-os`. The route is `/p/<project>`.
3. Scroll to the section `CONTRACT CHANGES`. It is directly after
   `CONFLICT HOTSPOTS`.

## What it shows

- Columns: TICKET (links to the parent issue in the repo of the step PR),
  STEP, PR (links to the PR), BACKUP, RESTORE, VERDICT (`pending` when empty),
  APPROVED BY, UPDATED. Newest first. Every header sorts.
- 0 rows: `No contract changes on this project.`
- A failed read: `could not load` and a RETRY button. It is never the empty
  state.
- The table scrolls inside its own wrapper (`div.contract-changes`,
  `overflow-x:auto`), so a 375 px page has no body horizontal scroll.

## Parts

- Panel: `console-ui/src/screens/ContractChangesPanel.js`, mounted in
  `console-ui/src/screens/Project.js`. One read:
  `GET /api/coord/contract-changes?project=<p>`.
- Route: `worker/jobs/src/routes/contract-changes.js`, bearer-gated.
  `POST /api/contract-changes` upserts on (project, parent_ticket, step);
  an empty field never overwrites a stored value.
  `GET /api/contract-changes?project=<p>[&parent_ticket=<n>][&step=<s>][&limit=<n>]`,
  capped by the settings row `lib.contract-change.contract_changes_list_max`
  (fallback 100).
- Writer: `cc_record` in `bin/lib/contract-change-record.sh`, through
  `bin/jobs-client.sh`. A failed write logs one line and returns 1.
- Table: `contract_changes`
  (`worker/jobs/schema.d/202611260538-bh-9929-contract-changes.sql`), index
  `idx_contract_changes_project_updated`. Retention:
  `worker/jobs/src/routes/retention.d/bh-9929-contract-changes.js` archives a
  row to `contract_changes_archive` after `retention.contract_changes.days`
  (730).
