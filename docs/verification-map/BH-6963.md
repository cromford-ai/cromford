# Repair on push (BH-6963, wave 1 of #6542)

**What it is:** `bin/repair-on-push.sh`, a hub lane at `* * * * *`
(`cron/lanes/733-repair-on-push.cron`, registry
`catalog/lanes.d/repair-on-push.json`). A push to a repo's default branch is a
`push` wake row written by `POST /webhooks/github` (`wakeOf` in
`worker/jobs/src/lib/core.js`). Its `event` is `push.<before>..<after>`.

Each tick the lane:

1. Reads `GET /api/wakes/cursor?all=1` (max id), then its own cursor
   (`GET /api/wakes/cursor?box=repair-on-push`). No cursor row: it plants the
   cursor at max id and stops.
2. Reads `GET /api/wakes?since=<cursor>&kind=push&limit=<REPAIR_PUSH_WAKES>`.
3. Per wake: maps the repo to a fleet project, reads
   `GET repos/<slug>/compare/<before>...<after>` once, and reads the repo's
   PRs from `GET /api/pr-state?repo=<slug>` (rows not in
   `REPAIR_PUSH_SKIP_STATES`).
4. Per PR: reads its files from `builds/<dir>/changed-files.txt` (the build of
   record for that PR url), else `GET repos/<slug>/pulls/<n>/files`. No shared
   file: `reason=no-overlap`. Else it reads `GET pulls/<n>` (open, not draft,
   base = BASE_BRANCH), `GET compare/<after>...<head>` (`ahead`/`identical` =
   `reason=current`), takes the conductor PR lock with `flock -n`, and calls
   `mc_rebase`.
5. Moves the cursor past each complete wake, and to max id when the whole list
   completed under its limit.

**Where to look:** `logs/repair-on-push.log`. One line per decision:

```
REPAIR pr=<n|-> files=<k> action=rebase|skip reason=<r> repo=<slug> wake=<id>[ rc=<rc>]
```

`reason` for a rebase is the `mc_rebase` answer: `pushed` (0), `conflict` (1),
`gate-red` (2), `lease` (3), `setup` (4), `rebind-failed` (5), `pool-queued`
(6), `pool-down` (7), `tmp-full` (8). A skip is one of `no-overlap`,
`budget`, `done-this-tick`, `closed`, `draft`, `base`, `current`, `rebasing`,
`locked`, `files-unreadable`, `pr-unreadable`, `compare-unreadable`,
`compare-gone`, `no-range`, `unowned-repo`. Each tick ends with
`tick wakes=<n> rebased=<calls> budget=<b> cursor=<c>`.

**Knobs:** settings rows `lane.repair-on-push.repair_push_budget` (default 8)
and `lane.repair-on-push.repair_push_wakes` (default 20). Off:
`flags/lane-off-repair-on-push`, `all-off`, `automerge-disabled`.

**Tests:** `worker/jobs/test/wake-push.bh-6963.test.js` (the route, on the real
schema in node:sqlite), `tests/repair-on-push.bh-6963-test.sh` (the real lane
against the real worker through `tests/lib/repair-on-push-worker.bh-6963.mjs`).
