| PR record writes (BH-8150, slice C1 of BH-8067): the fleet's own GitHub writes (labels, comments, PR state, queue requests, pushes) update the PR record after GitHub answered rc 0 | [entries/BH-8150.md](entries/BH-8150.md) | No screen. Lib `bin/lib/pr-record-write.sh`: `prr_write <repo> <n> <labels\|comment\|pull\|none> <extra-json\|-> <cmd...>` (runs the write unchanged, same rc, stdout and stderr; then one `pr_record_put` from GitHub's answer) and `prr_note_push <repo> <n> <at> <wt> <src> <lease>` (head_sha; a new sha also resets checks to {} and mergeable_state to unknown). Sites: `bin/lib/mc/queue.sh` (`mc_dequeue_label`, `mc_dequeue_surface`, `mc_merge`, `mc_enqueue_github`, `mc_mergify_command`, `mc_enqueue_mergify`, `mc_requeue_mergify`, `mc_cr_dequeue`), `bin/lib/mc/classify.sh` (`mc_label_remove`, `mc_nhv_unqueue`), `bin/lib/mc/rebase.sh` (`mc_retarget_base`, `mc_close_for_rebuild`, `mc_kick_ci`, the pushes of `mc_rebase` and `mc_restack`), `bin/merge-queue.sh` (`mq_land`, the rebase push), `bin/lib/rb/pr.sh` (hotfix label, qa-fix push, preview-QA comment), `bin/lib/rb-pr-labels.sh` (`prl_apply`), `bin/lib/rb-full-ci-label.sh` (`fcl_apply`). queue_state values: `requested`, `dequeue_requested`, `merge_requested` (what the fleet asked for, never what the queue did). Writes only when the caller already loaded the jobs client. Knob `PR_RECORD_WRITES` (`catalog/lanes.d/_lib.pr-record-write.json`, default 1, 0 = no record writes). Log `logs/pr-record.log`: `write <repo>#<n> <kind> put=failed (<status>): record writes off for pid <pid>` (once per process; a per-process latch file in TMPDIR then stops the writes).
