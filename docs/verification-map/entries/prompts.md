Editor: console-ui/src/ui/PromptEditor.js. Round 1 reads the list (and the fleet list for a project) in parallel; round 2 reads the head body, the version before it and the fleet head body in parallel. `textarea.prompt-editor__text` (full width) holds the head body (a project with no head starts from the fleet body, else empty). `[data-testid="diff-previous"]` diffs against the previous version ("No saved version yet.", "No previous version.", "Version <n> is archived."); `[data-testid="diff-above"]` diffs against the fleet head, or names the repo file and says "The console cannot read it.". The lint lines (`role="status"`, "Missing marker: <m>" or "Markers: all present") come from catalog/prompt-markers.json and show only for a kind with markers. SAVE (off until the text changes) opens the confirm modal (`role="dialog"`); its note textarea must not be blank before SAVE VERSION is enabled; CANCEL or Escape sends nothing. A 201 goes back to the list; a refusal is a `role="alert"` line (422 names each missing marker, 409, 413, empty body) and the text stays. History (BH-7972, BH-7940.4; console-ui/src/ui/PromptHistoryActions.js): VERSIONS (no read before the click) opens `div.prompt-versions` (`role="dialog"`, `aria-label="Versions of <kind>"`; a bottom sheet under 640 px; CLOSE or Escape closes) with `.skel` rows, then a `SortableTable` VERSION / WHO / WHEN / NOTE and a RESTORE button per row ("No saved versions." when empty; "could not load — <why>" on a failed read), from `GET /api/prompts/<scope>/<kind>/versions`.
