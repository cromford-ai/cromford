# stage_events_daily archive rule (BH-7109)

**What it is:** a retention rule that moves daily rollup rows of
`stage_events_daily` to the archive D1 (env.ARCHIVE). It is off by default.
Details: [the note](../notes/2026-10-16-BH-7109-stage-events-daily-archive.md).

- Route (harness-jobs, bearer-gated): `POST /api/retention/run {dry_run?}`.
  Its `rules[]` has the entry `stage_events_daily.archive`.
- Mover: `worker/jobs/src/lib/archive-daily.js` (copy, count back by key and
  `n`, then the hot delete by rowid and `n`).
- Settings row: `retention.stage_events_daily.archive_days` (seed `'0'` = off).
- Caller: the hourly hub lane `bin/d1-retention.sh`.

## Preconditions

- The rule is off until an operator sets `archive_days` above 0.
- With the rule on and ARCHIVE unbound, the entry has
  `error: "archive not bound"` and the rule deletes nothing.

## Check after deploy

```bash
curl -s -X POST -H "Authorization: Bearer $HARNESS_SECRET" -d '{"dry_run":true}' \
  "$JOBS_URL/api/retention/run" | jq '.rules[] | select(.rule=="stage_events_daily.archive")'
```

Expected: `"off": true` and `"error": null`.
