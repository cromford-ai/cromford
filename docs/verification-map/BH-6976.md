# Wake backstops for three GitHub pollers (BH-6976)

**What it is:** three pollers read the wake mirror before they read GitHub.
Between backstops, only a wake for the item makes the lane read GitHub for it
again. The full poll stays as a backstop of at least 30 min. The decision is
`wb_due` in `bin/lib/wake-backstop.sh`. It reads wakes through
`prs_wake_seen` (`bin/lib/pr-snapshot-wakes.sh`) and never acks one. A feed
that cannot tell (rc 2) is a read.

- `bin/orphan-reconcile.sh`: a per-issue thread (`issues/N/comments`) or
  blocker (`issues/N`) read is reused from
  `state/orphan-reconcile/<owner>_<repo>/<thread|blocker>-N.{json,meta}` while
  no `issue`/`pr` wake for N arrived, (thread) the open list's updatedAt for N
  is unchanged, and the copy is younger than `ORPHAN_WAKE_BACKSTOP_S` (1800).
  The run summary carries `cache=<hits>/<reads>`.
- `bin/decompose-parent-close.sh --cooled`: past the 600 s cooldown, the
  GitHub-board pass runs only on an `issue` wake for a key in
  `state/parent-close-<project>.keys`, a `retry` line, or once the last pass is
  `PARENT_CLOSE_BACKSTOP_S` (1800) old. In-app boards and hand runs are not
  gated.
- `bin/lib/stuck-work/facts-pr.sh` (`_swf_ci_hit`): with a healthy feed and no
  `checks <head>` or `pr <n>` wake, a cached CI line lasts up to
  `STUCK_WORK_CI_QUIET_TTL_S` (1800) instead of `STUCK_WORK_CI_TTL_S` (900).

**How to drive it:**

| what | how |
|---|---|
| the decision table (WB1-WB16) | `HARNESS_TEST_SANDBOX=1 bash tests/wake-backstop.bh-6976-test.sh` |
| lane A (O1-O8, O8 on the real feed) | `HARNESS_TEST_SANDBOX=1 bash tests/orphan-reconcile-wake.bh-6976-test.sh` |
| lane B (P1-P9) | `HARNESS_TEST_SANDBOX=1 bash tests/decompose-parent-close-wake.bh-6976-test.sh` |
| lane C (S1-S9) | `HARNESS_TEST_SANDBOX=1 bash tests/stuck-work-wake.bh-6976-test.sh` |
| on the hub | `grep -o 'cache=[0-9]*/[0-9]*' logs/<project>.log \| tail`, `grep 'parent-close: pass on' logs/<project>.log`, `ls state/orphan-reconcile/` |

**What must never regress:**

- A wake for the item, a moved updatedAt (lane A), the backstop, or a feed
  that cannot tell always causes the read (O1, O3, O4, O5, P4, P5, S1, S3-S5).
- With no wake, no GitHub call for the item inside the backstop (O2, P2, S2).
- The 600 s floor of lane B holds even with a wake (P6).
- A failed read is never cached (O6); a failed close is retried after the
  floor (P8).
- `WAKE_BACKSTOP=0` and each knob at 0 restore the pre-BH-6976 cadence (O7,
  P9, S6).

**Metric to watch:** counted calls per (lane, class) in
`bin/gh-budget-report.sh --window 24h` on the hub, 24 h after deploy, for
`orphan-reconcile.sh` (issues/N/comments, issues/N), `decompose-parent-close.sh`
(pulls) and `stuck-work.sh` (commits/SHA/check-runs).
