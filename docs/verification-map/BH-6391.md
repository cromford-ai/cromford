# Lead re-review: the earlier review, the delta, and the NOTE rule (BH-6391)

**What it is:** a lead review request for a head after an earlier reviewed head
G carries a `lead-prev:` scope-note group (G, its word, its report path, the own
commits and files and the main files since G). The reviewer shows it as
`## Re-review`, and after a BLOCK on an approved G it keeps findings on lines
unchanged since G as NOTEs. The land lane logs a verdict flip with no own
commit. Details: [the note](../notes/2026-10-13-BH-6391-rereview-delta-scope.md).

- Lib: `bin/lib/lead-prev.sh` (`lpv_delta_files`, `lpv_note`, `lpv_parse`,
  `lpv_fit`, `lpv_section`, `lpv_downgrade`, `lpv_flip`).
- Writer: `bin/lead-review-enqueue.sh` (hub cron, `request()` fits the notes to
  4000 chars). Log `logs/lead-review-enqueue.log`.
- Reader: `bin/lead-review.sh` `review_one` (`# >>> re-review` block, the NOTE
  pass before the report write). Log `logs/lead-review.log`.
- Flip line: `bin/lead-review-land.sh` step 2a-flip, marker
  `state/lead-review-land/flip-<id>`. Log `logs/lead-review-land.log`.

**How to drive it:**

| what | how |
|---|---|
| the lib, the enqueue, the reviewer and the land lane, run whole | `HARNESS_TEST_SANDBOX=1 bash tests/lead-review-delta-scope.bh-6391-test.sh` |
| a request after a reviewed head, on the hub | `grep 're-review of' logs/lead-review-enqueue.log` |
| the NOTE pass, on a lead review box | `grep 'kept as NOTE' logs/lead-review.log` |
| the flip count, on the hub | `grep -c ' flip ' logs/lead-review-land.log` |

**What usually lies:** a group with `?` lists means git could not answer, not
"no delta". A request filed by hand or in a build has no group.

**What must never regress:**

- A BLOCK on a changed line, on a line main changed, on a range that crosses a
  changed line, `[BLOCK needs-human]`, a BLOCK with no `path:line`, a
  `main-cause:` naming a main file of the delta, an `own-cause:` naming an own
  file of the delta, a path that is not a file at the head (`x.sh` for
  `bin/x.sh`, `./bin/x.sh`, a missing file), an earlier BLOCK word, and git
  that cannot read G each stay BLOCK (D2b-D2f, D3a, D3b, D3d, U4, U7).
- The flip line is one line per request and never stops a post or a stamp (D4a).
