# Merge lock as a project lease, re-review cap in D1 (BH-6887)

**What it is:** the merge conductor's merge lock also takes the D1 project
lease `merge-conductor <project>` (BH-6883), and each landing write checks the
held fence first. The operator-set daily re-review cap (`MC_REREVIEW_DAILY_CAP`)
spends a D1 counter instead of counting a box file. Details:
[the note](../notes/2026-10-17-BH-6887-mc-lease-budget.md).

- Lock (`bin/lib/mc/locks.sh`, `mc_merge_locked <project> <cmd…>`):
  - hub: the box flock, then the lease. Held elsewhere: rc 99. Not answered:
    the call runs under the flock only.
  - lane-run machine (`MC_ON_MACHINE=1`): the lease instead of the flock. Held
    elsewhere or not answered: rc 99. `mc_merge`/`mc_enqueue` run only under a
    lease an outer owner exported (`MC_LEASE_FENCE`); without one they write
    their deferred word and answer 99, as before.
  - The command sees `MC_LEASE_FENCE`, `MC_LEASE_PROJECT`, `MC_LEASE_HOLDER`.
    The lease is released after the call.
- Fence check `mc_lease_fence_ok`: in `mc_merge`, `mc_enqueue`,
  `conductor_settle`, `mc_close_shipped`. No fence held: no check.
- Routes (harness-jobs, `worker/jobs/src/routes/mc-budget.js`, bearer-gated):
  - `POST /api/mc-budget/take {project, kind, limit}`: 200
    `{granted:true, day, spent}` or 200 `{granted:false, day}`.
  - `POST /api/mc-budget/give {project, kind, day}`: 200 `{given}`.
  - 400 for a bad `project`, `kind`, `limit` (1..1000000) or `day`.
- Table `mc_budget (project, day, kind, spent)`, PRIMARY KEY
  `(project, day, kind)`. Row `retention.mc_budget.days` (30); rule
  `mc_budget.age`.

**How to drive it:**

| what | how |
|---|---|
| the lock, the lease and the fence checks, over the real worker | `HARNESS_TEST_SANDBOX=1 bash tests/mc-locks-lease.bh-6887-test.sh` |
| the budget routes, the shell client, the cap in `headbound_review`, retention | `HARNESS_TEST_SANDBOX=1 bash tests/mc-budget.bh-6887-test.sh` |
| one take and give on a live worker | `curl -s -X POST -H "Authorization: Bearer $HARNESS_SECRET" -d '{"project":"probe","kind":"probe","limit":1}' "$JOBS_URL/api/mc-budget/take"` |

**What must never regress:**

- A machine never lands while another holder has the lease (L1).
- A stale fence never reaches a GitHub write (L2, L8, L9).
- On the hub a lease outage never stops a landing (L5).
- Two takes of the last unit: exactly one wins (B4).
- A denied take is a 200, never confused with an outage (B6).
- Cap 0 makes no D1 call (B7).
- The spend and the give use the primary key (B5).
