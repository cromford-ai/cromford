# Merge conductor wake consumer (BH-6975, wave 2 of #6545)

**What it is:** `bin/merge-conductor-wake.sh`, a hub lane at `* * * * *`
(`cron/lanes/413-merge-conductor-wake.cron`, registry
`catalog/lanes.d/merge-conductor-wake.json`). A PR event or a check answer is a
`pr` or `checks` wake row written by `POST /webhooks/github` (`wakeOf` in
`worker/jobs/src/lib/core.js`). A `pr` key is the PR number. A `checks` key is
a head sha.

Each tick the lane:

1. Reads `GET /api/wakes/cursor?all=1` (max id), then its own cursor
   (`GET /api/wakes/cursor?box=merge-conductor-wake`). No cursor row: it plants
   the cursor at max id and stops.
2. Pays the carry first (`state/merge-conductor-wake/carry.tsv`): keys whose
   launch `kw_conductor` deduped on an earlier tick.
3. Reads `GET /api/wakes?since=<cursor>&limit=<MC_WAKE_WAKES>` and acts on the
   `pr` and `checks` rows in id order. A checks sha maps through
   `state/merge-conductor/pr-state.tsv` (open rows), else one
   `GET repos/<repo>/commits/<sha>/pulls`.
4. Per PR: skips a repo no `fleet.conf` project owns and a `not-harness <key>`
   line in `state/merge-conductor/attempts.txt`; else
   `MC_KEYED_WAKE_MIN_S=<MC_WAKE_MIN_S> kw_conductor <slug> <n>`, which starts
   `MC_ONLY_PR=<slug>#<n> bin/merge-conductor.sh` detached.
5. Stops at `MC_WAKE_BUDGET` starts (`hold budget`, the wake stays above the
   cursor), then PUTs the cursor once: the last complete wake, or max id when
   nothing was held and the list came back under its limit.

**Where to look:** `logs/merge-conductor-wake-cron.log`. One line per decision:

```
WAKE pr=<n|-> event=<ev> latency_s=<s|-> repo=<slug> wake=<id|carry> action=tick|skip|carry|hold reason=<r>
```

Each tick ends with `tick wakes=<n> pc=<pr+checks> ticks=<started> carried=<n> budget=<b> cursor=<c>`.
The matching keyed ticks are in `logs/merge-conductor.log`.

**Knobs:** settings rows `lane.merge-conductor-wake.mc_wake_budget` (10),
`.mc_wake_wakes` (100), `.mc_wake_min_s` (30), `.mc_wake_max_age_s` (900),
`.mc_wake_sha_lookups` (5). Off: `flags/lane-off-merge-conductor-wake`,
`all-off`, `switch.factory-stop`, `automerge-disabled`,
`lane-off-merge-conductor`, `lane.merge-conductor.mc_keyed_wake=0`.

**Tests:** `tests/mc-wake-consumer.bh-6975-test.sh` (the real lane against the
real worker through `tests/lib/mc-wake-worker.bh-6975.mjs`, the real
`kw_conductor`, a stub conductor and a stub `gh`).
