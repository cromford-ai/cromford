# Hotspot split tickets (BH-6739)

**What it is:** a weekly hub lane that files a split ticket for a file that
collides too often, once per file.

- `bin/hotspot-split-ticket.sh` reads `GET
  /api/conflict-hotspots?project=cromford&limit=10`, the stored output of
  `bin/conflict-hotspots.sh --ref origin/main --top 10` from the owner box. It
  stops when that run is absent, names another repo, or is older than the
  settings row `hotspots.split_max_age_days` (no row = 14).
- A row is filed when its conflicts are at least the settings row
  `hotspots.split_threshold` (no row = 10), its path matches no glob in
  `catalog/list-files.tsv`, it has no `hotspot_tickets` row, a contents read on
  main does not answer 404, and no open issue carries
  `<!-- harness-hotspot-split: <path> -->`.
- The issue is `ai-build`, titled `Split <path>: <k> conflicts in <days> days`,
  body from `prompts/hotspot-split-ticket.md`. The row is written after it.
- A threshold or max age out of range, an unreadable or stale measurement, an
  unreadable or truncated row list, or an unknown issue list stops the run:
  nothing is filed, the summary line has `stopped=<why>`, one warn alert.
- Retention: rule `hotspot_tickets.age` deletes a row after the settings row
  `retention.hotspot_tickets.days` (365); index `idx_hotspot_tickets_filed`.
- Off: `flags/lane-off-hotspot-split-ticket`.

**How to drive it:**

| what | how |
|---|---|
| the lane, real worker, stub gh | `HARNESS_TEST_SANDBOX=1 bash tests/hotspot-split-ticket.bh-6739-test.sh` |
| the stored input | `GET /api/conflict-hotspots?project=cromford&limit=10` |
| the routes, the index plan, the retention rule | `cd worker/jobs && node --test test/hotspot-tickets.bh-6739.test.js` |
| a dry run on the hub | `/root/harness/bin/hotspot-split-ticket.sh --dry-run; tail -n 5 /root/harness/logs/hotspot-split-ticket.log` |
| the rows on the hub | `GET /api/hotspot-tickets?repo=example-org/cromford` |
| the filed issues | `gh issue list -R example-org/cromford --search "Split in:title label:ai-build"` |
