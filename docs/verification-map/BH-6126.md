# Lane-run Fly fleet: the autoscaler (BH-6126)

**What it is:** the hub starts and stops machines in the Fly app `lane-run`.
Each machine runs `bin/lane-run-worker.sh` (BH-6124) and claims queued lane
runs. Details: [the note](../notes/2026-10-12-BH-6126-lane-fleet.md).

- Tick (`bin/lane-fleet.sh tick`, hub cron every minute behind
  `hub-lease.sh check`, `flock -n locks/lane-fleet.lock`): reads
  `GET /api/lane-runs/stats`, `flyctl machine list -a lane-run --json` and
  `GET /api/lane-fleet/machines`. At most one start or one stop per tick.
  Log: one `tick wait=... live=... inflight=... action=... cost=w/a` line in
  `logs/lane-fleet.log`. Off: `flags/lane-off-lane-fleet`.
- Rule (`lf_decide`, `lf_pick_stop`): a start in flight -> no start; a
  failed start (no claim in `lane_fleet.start_grace_s`, or exited at boot)
  -> stop it, one ALERTS line, no start for
  `lane_fleet.failed_start_backoff_s`; at `lane_fleet.max_machines`
  (0 = no ceiling) -> no start; below `lane_fleet.warm_floor` -> start;
  oldest queued wait over `lane_fleet.scale_up_wait_s` -> start. With no
  start due and an empty queue, the most idle machine over
  `lane_fleet.idle_stop_s` stops, never below the floor.
- Image: `lane_fleet.image` is used only when it names
  `registry.fly.io/lane-run`.
- Record (harness-jobs, `worker/jobs/src/routes/lane-fleet.js`):
  `GET /api/lane-fleet/machines`, `POST /api/lane-fleet/machines`,
  `POST /api/lane-fleet/cost`. Table `lane_machines`
  (`worker/jobs/schema.d/0022-bh-6047-lane-fleet.sql`). Cost rows land in
  `cost_rows` with box `lane-run-<machine id>`, stage `infra`, runner `fly`,
  `lane_id` = the lane the machine ran in that minute, else `lane-fleet`.
- Machine (`fly/lane-run.toml`, `fly/lane-run.Dockerfile`,
  `fly/lane-run-entrypoint.sh`): secrets come from Fly secrets, written to
  mode-600 env files at boot.

**How to drive it:**

| what | how |
|---|---|
| the tick, over the real worker and a stub flyctl | `HARNESS_TEST_SANDBOX=1 bash tests/lane-fleet.bh-6126-test.sh` |
| the routes alone | `cd worker/jobs && node --test test/lane-fleet.bh-6126.test.js` |
| the last ticks on the hub | `tail -n 5 /root/harness/logs/lane-fleet.log` |
| the machines on Fly | `flyctl machine list -a lane-run` |
| the record on a live worker | `curl -sS -H "authorization: Bearer $HARNESS_SECRET" "$JOBS_URL/api/lane-fleet/machines"` |
