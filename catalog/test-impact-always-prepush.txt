# (bin/prepush-gate.sh) runs on the builder: its fast-lints set and its
# rules-pack suite components (BH-7289, wave 3 of #7033).
#
# WHY. A merge-queue batch re-ran every always-suite, also the ones the gate
# had just run green on each member's head. bin/ci-plan.sh now drops a suite
# of this list from a batch when EVERY member's PR body carries a
# `prepush-gate-record v1` block (bin/lib/prepush-record.sh) whose head is the
# member's head and that names the suite. The drop is this list ∩ every
# member's record, minus the quarantine; the regression list adds a suite back.
# One member with no record, a moved head, the `full` label or unreadable
# members, and the batch runs this list. The knob is the settings row
# CI_ALWAYS_PREPUSH_SKIP of the ci-plan-settings lane (default 1, 0 = off).
#
# The suites STAY in catalog/test-impact-always.txt and in the derived always
# set: that set feeds the gate's own list (bin/fast-lints.sh --list), so a line
# moved out of it would leave the gate too.
#
