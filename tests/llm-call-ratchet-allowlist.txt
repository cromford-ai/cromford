# tests/llm-call-ratchet-allowlist.txt — BH-1141 phase 1.
#
# THE RULE: a vendor model call lives in bin/agent-call.sh, where it can be
# seen, priced and refused before it is made. Every OTHER file that invokes a
# model is written down here with the reason it is not converted, and every one
# of them must also appear in catalog/llm-sites.json so the inventory cannot go
# stale while this list grows.
#
# The list only ever gets SHORTER. Adding a line is a decision somebody makes on
# purpose, in a PR, with a sentence; a new raw call that nobody wrote down turns
# tests/llm-call-ratchet-test.sh red.
#
# Format: <path from repo root><TAB><reason>
bin/claude-cost.sh	The thin priced wrapper for callers that genuinely need raw claude (orchestrator turns, greenfield, box-chat's -c continuation). Writes through the same cost_append as agent-call, so the money is visible — but it consults no lane knob, which is the phase-2b gap this inventory exists to name.
bin/box-chat.sh	Runtime path "$CHAT_CLAUDE" (BH-2308 made the scanner see it): it is bin/claude-cost.sh, the priced wrapper, for the -c continuation agent-call cannot resume; the bare CLI only when the wrapper is missing from the box. Priced, ungated: the claude-cost gap already on this list.
bin/greenfield.sh	Runtime path "$CLAUDE_BIN" (BH-2308 made the scanner see it): bin/claude-cost.sh, the priced wrapper, with the bare CLI only when the wrapper is missing. Operator-run pack generator; priced, ungated, the claude-cost gap already on this list.
bin/grok-envelope-probe.sh	Runtime path "$GROK" (BH-2308 made the scanner see it). A hand-run probe of the grok CLI's JSON envelope: it exists to test the raw CLI agent-call wraps, so it cannot go through agent-call; it writes its own priced cost row and records the call in the job ledger before and after.
bin/orchestrate.sh	The PRIMARY turn only (run_turn): "$ORC_CLAUDE" -p behind a ${ORC_TOKEN:+CLAUDE_CODE_OAUTH_TOKEN=...} word, which the scanner could not see until the BH-2308 review. $ORC_CLAUDE is bin/claude-cost.sh (priced, ungated; catalog site orchestrate-primary), the bare CLI only when the wrapper is missing. The SURVIVAL turn goes through agent-call.sh since BH-2307, and case 8 of the ratchet holds it there.
bin/lib/vendor/fireworks.sh	BH-7965: a key proof call for the secret envelope, one GET <base>/models per applied envelope, no inference. The scanner matches the fallback base URL. The envelope delete-on-read is the dedup; unpriced because /models is not billed.
bin/lib/vendor/claude.sh	BH-7965: a key proof call for the secret envelope, one `claude -p` with `ping` per applied envelope, through vendor_cli_probe in bin/lib/vendor/_common.sh ("$@", which the scanner cannot see). Not priced: it must prove the NEW token, which agent-call would not use. The envelope delete-on-read is the dedup.
bin/lib/vendor/codex.sh	BH-7965: a key proof call for the secret envelope, one `codex exec` with `ping` per applied envelope, through vendor_cli_probe in bin/lib/vendor/_common.sh ("$@", which the scanner cannot see). Not priced: it must prove the NEW key, which agent-call would not use. The envelope delete-on-read is the dedup.
