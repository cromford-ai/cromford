# tests/hold-push-ratchet-allowlist.txt — BH-2504.
#
# THE RULE: a lane that writes a PR branch pushes through bin/lib/hold-push.sh
# (hold_push), which re-reads the ticket's HOLD at the push and pushes under a
# lease on the sha the round started from. Every OTHER file under bin/ that runs
# `git push`, or writes a ref over REST (`git/refs`), is written down here with
# the reason its branch is not a PR branch. A new raw push that nobody wrote
# down turns tests/hold-push-ratchet.bh-2504-test.sh red.
#
# The list only ever gets SHORTER. Adding a line is a decision made on purpose,
# in a PR, with a sentence.
#
# Format: <path from repo root><TAB><reason>
bin/batch-resolve.sh	Pushes and deletes its OWN train branches (`batch/<project>/<stamp>-…`, batch_branch_name), which no ticket owns. The member PR branches it rebases go through mrt_rebase_pure (bin/lib/mc/train.sh), which pushes through hold_push.
bin/deploy-train.sh	Pushes a `rollback/<stamp>` branch it cut itself for a revert PR.
bin/feature-map-draft.sh	Pushes its own `feature-map/draft` branch.
bin/guardrail-promote.sh	Pushes its own `guardrails/<slug>-<date>` branch.
bin/qa-personas.sh	Pushes its own `qa/personas-<date>` branch.
bin/rule-miner.sh	Pushes its own `rules/mined-<date>` branch.
bin/lib/onboard-stations.sh	The load-project.sh registry station (moved from bin/load-project.sh by BH-7948): the operator's own checkout of this repo, publishing a registry commit before a box syncs. Not a lane and not a PR branch.
bin/publish-share.sh	Pushes the public repo's main as a fast-forward (a separate repository), never a branch of a fleet repo.
bin/iron-law-guard.sh	Not a push: the text of the deny messages its push-main rule prints.
bin/lane-fence.sh	Not a push: the command string handed to the fence's classifier from the pre-push hook.
bin/mergify-sync.sh	POSTs a NEW ref for its own config branch; it never moves an existing one.
bin/flaky-quarantine.sh	POSTs a NEW ref for its own quarantine branch; it never moves an existing one.
bin/lib/gh-pr-merge.sh	DELETEs the head ref of a PR it has just merged; it writes no content to a branch.
bin/lib/gh-shim/pr-write.sh	The `gh pr merge --delete-branch` shim: DELETEs the head ref after the merge; it writes no content to a branch.
bin/lib/mrb-act.sh	Pushes a main-red-revert/pr-<N>-<sha12> branch it cut itself for a revert PR.
bin/lesson-propose.sh	POSTs a NEW ref for its own `harness/lesson-<category>-<fp8>` branch, which no ticket owns, and writes its one file over the contents API. A 422 (the branch exists) only reads the ref back; it never moves it.
bin/lesson-measure.sh	POSTs a NEW ref for its own `harness/lesson-retire-<category>-<id>` branch, which no ticket owns, and writes its one file over the contents API. A 422 (the branch exists) only reads the ref back; it never moves it.
bin/reference-shots.sh	Pushes an orphan commit of QA screenshots to its own `harness-shots/<key>-<yyyymmdd>` branch, which no ticket owns and no PR is opened from, and its prune deletes only refs under `refs/heads/harness-shots/`. It never writes the PR branch.
bin/roadmap-render.sh	POSTs a NEW ref for its own `roadmap/render-<project>` branch, which no ticket owns, and writes its one file (docs/ROADMAP.html) over the contents API; it never moves an existing ref (BH-7265).
